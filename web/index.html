操作手册

  1. 切换卡片 首页上滑 / 下滑在轮盘里切换，松手自动吸附居中；也可以点顶部切到「列表模式」一屏看全部。
  2. 搜索卡片 首页轮盘上方有搜索框：输入 App 名、账号片段、分类或备注中的任意字样，轮盘与列表都会即时过滤；点右侧 ✕ 清空恢复全部。
  3. 查看与复制 点卡片进入详情：账号直接可见，密码点眼睛显形；两个复制键分别复制账号、密码，密码复制后 60 秒自动清空剪贴板。
  4. 模板库建卡 右上「模板库」里有 60+ 主流 App，点一下即预填名称、配色、图标和分类，补上账号密码保存就行。
  5. 自定义卡片 右上「＋」新建：密码可点「生成」得到 16 位强密码；图标 28 选 1；配色 10 套预设，或点彩色圆点自己拖 RGB。
  6. 分类与收藏 底部「分类」按用途分组、「收藏」放常用账号；详情页可一键收藏 / 取消收藏。
  7. 主密码 「我的 → 主密码」设置 6 位数字，之后每次启动或从后台切回来都要解锁。
  8. 备份与迁移 「我的 → 导出备份」生成 JSON 走系统分享；换机后用「从剪贴板导入」把备份粘回来即可恢复。

  • 「清空全部卡片」加弹窗二次确认，防止误删
  • 版本号升至 0.5（iOS 0.5 / build 5，Android 0.5 / versionCode 5）
